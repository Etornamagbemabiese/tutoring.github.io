# Personal Portfolio Website

A modern, responsive portfolio website showcasing professional experience, education, and achievements.

## Features

- 🎨 Modern, clean design with smooth animations
- 📱 Fully responsive for all devices
- ⚡ Fast loading and optimized performance
- 🎯 Interactive experience cards with flip animations
- 🌟 Professional color scheme and typography

## Running Locally

### Option 1: Python Server (Recommended)

```bash
python3 server.py
```

Then open your browser to: `http://localhost:8000`

### Option 2: Python Simple Server

```bash
python3 -m http.server 8000
```

### Option 3: Node.js (if you have it installed)

```bash
npx http-server -p 8000
```

## Files Structure

- `index.html` - Homepage
- `about.html` - About page
- `experience.html` - Work experience and leadership roles
- `education.html` - Educational background
- `contact.html` - Contact information
- `styles.css` - All styling and design
- `script.js` - Interactive functionality
- `server.py` - Local development server
